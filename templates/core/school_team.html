Como funciona

  1. Gere um código para o perfil (um para professores, outro para a secretaria…).
  2. Envie o código ou o link por mensagem.
  3. Cada pessoa cria o próprio usuário e senha com o código e já entra ligada a esta escola.

Segurança: cada código vale para um perfil, por um prazo e um número de cadastros. Cancele quando a equipe estiver completa. Secretaria e administração, que veem os dados de todos os estudantes, pedem aprovação por padrão.

Professores só veem estudantes depois de atribuídos às turmas; a coordenação, depois da designação.
